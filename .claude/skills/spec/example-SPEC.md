# 오늘도 1차 버전 스펙

## 목표

- 매일 하려는 습관을 실천했는지 가볍게 기록하고, 연속 일수와 달력으로 얼마나 꾸준히 이어 왔는지 한눈에 확인해 계속할 동기를 얻는다.
- 가입이나 설치 없이 지금 쓰는 브라우저에서 바로 쓴다.

## 이번에 만드는 기능

### 습관 관리

- 이름만 입력해 습관을 등록한다.
- 이름은 앞뒤 공백 제거 후 1~20자이며 빈 값, 줄바꿈, 동일 이름을 허용하지 않는다.
- 모든 습관은 별도 요일 설정 없는 매일 습관이다.
- 새 습관은 등록순으로 목록 끝에 추가하며 자동으로 오늘 완료 처리하지 않는다.
- 이름 변경 시 시작일과 체크 기록은 유지한다.
- 삭제 시 기록도 영구 삭제된다는 확인을 받은 후 제거한다.
- 직접 재정렬 기능은 제공하지 않는다.

### 습관 선택과 오늘 체크

- 습관 목록에서 하나를 선택하면 해당 습관의 연속 일수와 달력을 표시한다.
- 목록과 달력 양쪽에서 오늘 완료 여부를 토글할 수 있으며 두 화면은 즉시 동기화된다.
- 새 습관을 만들면 해당 습관을 선택한다.
- 재접속 시 마지막 선택을 복원하지 않고 등록순 첫 습관을 선택한다.
- 선택된 습관 삭제 후에는 다음 습관을 선택하고, 다음 습관이 없으면 이전 습관을 선택한다.

### 달력과 기록

- 달력은 월요일부터 시작하며 처음에는 현재 달을 표시한다.
- 오늘과 지난 날짜는 자유롭게 체크하거나 해제할 수 있다.
- 미래 날짜는 비활성화한다.
- 과거 기록을 수정하면 연속 일수를 즉시 다시 계산한다.

### 연속 일수

- 최고 기록이나 누적 통계가 아닌 현재 연속 기록만 표시한다.
- 오늘이 체크되어 있으면 오늘부터 과거 방향으로 연속된 일수를 계산한다.
- 오늘이 아직 체크되지 않았지만 어제가 체크되어 있으면 어제까지의 연속 기록을 유지한다.
- 어제도 체크되지 않았다면 현재 연속 일수는 0일이다.
- 체크 기록이 전혀 없어도 0일로 표시한다.

### 날짜와 저장

- 브라우저의 현재 현지 날짜를 '오늘'로 사용한다.
- 기록 날짜는 시간대 없는 현지 달력 날짜(`YYYY-MM-DD`)로 저장하므로 시간대가 바뀌어도 기존 날짜를 이동시키지 않는다.
- 자정을 넘기거나 탭이 다시 활성화되면 오늘, 달력, 연속 일수를 갱신한다.
- 브라우저 저장 데이터에 데이터 형식 버전, 습관 ID, 이름, 등록일, 완료 날짜 목록과 등록 순서를 보관한다.
- 새로고침하거나 브라우저를 다시 열어도 기록을 복원한다.
- 저장소 접근, 데이터 파싱 또는 쓰기에 실패하면 한국어 오류를 표시하고 변경 기능을 막는다.
- 손상된 데이터를 빈 데이터로 덮어쓰지 않으며, 쓰기에 실패한 화면 변경은 되돌린다.
- 데이터가 현재 브라우저에만 저장되고 브라우저 데이터 삭제 시 복구할 수 없음을 화면에 안내한다.

### 화면 상태

- 습관이 없을 때 기능 설명과 첫 습관 등록 행동을 제공한다.
- 모바일에서는 목록과 상세를 세로로, 넓은 화면에서는 나란히 배치한다.
- 모든 버튼, 오류, 확인창, 빈 상태와 날짜 관련 문구를 한국어로 제공한다.

## 안 하는 것

- 알림과 리마인더
- 로그인, 서버 저장과 여러 기기·브라우저 간 동기화
- 최고 연속 기록, 누적 통계와 차트
- 요일 지정, 주 N회, 횟수형 습관
- 습관 직접 재정렬과 보관함
- 데이터 내보내기·가져오기와 삭제한 습관 복구
- 스크린 리더 대응과 키보드 전용 조작

## 완료 조건

- AC-1: 습관이 하나도 없으면 앱이 무엇을 하는지 설명하는 문구와 첫 습관 등록 입력이 표시된다.
- AC-2: 이름을 입력해 습관을 등록하면 목록 끝에 추가되고 그 습관이 선택되며, 오늘은 체크되지 않은 상태이고 연속 일수는 0일이다.
- AC-3: 앞뒤 공백을 제거한 이름이 비어 있거나, 20자를 넘거나, 줄바꿈을 포함하거나, 기존 습관 이름과 같으면 등록과 이름 변경 모두 저장되지 않고 이유를 알려 주는 한국어 오류가 표시된다.
- AC-4: 습관 이름을 바꾸면 목록과 상세에 새 이름이 표시되고 체크 기록과 연속 일수는 그대로다.
- AC-5: 삭제를 누르면 기록도 영구 삭제된다는 확인창이 뜬다. 확인하면 습관과 기록이 사라지고, 취소하면 아무것도 바뀌지 않는다.
- AC-6: 선택된 습관을 삭제하면 바로 다음 습관이 선택되고, 다음 습관이 없으면 이전 습관이, 남은 습관이 없으면 AC-1의 빈 상태가 표시된다.
- AC-7: 목록이나 달력에서 오늘 또는 지난 날짜를 체크하거나 해제하면 목록의 오늘 표시, 달력, 연속 일수가 즉시 함께 바뀐다.
- AC-8: 미래 날짜는 체크할 수 없고, 달력은 이번 달 다음 달로 넘어갈 수 없다.
- AC-9: 연속 일수는 오늘이 체크되어 있으면 오늘부터, 아니면 어제부터 과거로 끊기지 않고 체크된 날 수다. 예를 들어 오늘·어제·그제가 체크되어 있으면 3일, 오늘은 미체크이고 어제·그제가 체크되어 있으면 2일, 오늘과 그제만 체크되어 있으면 1일, 오늘과 어제가 모두 미체크이면 0일이다. 월말과 다음 달 1일, 12월 31일과 다음 해 1월 1일처럼 월이나 연도가 바뀌어도 끊기지 않고 이어서 센다.
- AC-10: 앱을 열어 둔 채 자정이 지나거나 다음 날 탭으로 돌아오면, 새 날짜가 오늘로 표시되고 연속 일수가 새 날짜 기준으로 다시 계산된다.
- AC-11: 습관을 등록·변경·삭제하거나 날짜를 체크한 뒤 새로고침하거나 브라우저를 다시 열면, 습관 목록과 순서, 체크 기록이 그대로 남아 있고 첫 습관이 선택된다.
- AC-12: 저장된 데이터가 손상되었거나 브라우저 저장소에 접근할 수 없으면 한국어 오류가 표시되고 모든 편집이 막히며, 기존 저장 데이터는 덮어쓰이지 않는다.
- AC-13: 변경을 저장하지 못하면 한국어 오류가 표시되고 화면은 변경 전 상태로 돌아가며, 이후 편집이 막힌다.
- AC-14: 데이터가 이 브라우저에만 저장되고 브라우저 데이터를 지우면 복구할 수 없다는 안내가 화면에 표시되며, 습관 기록을 위해 외부 서버로 요청을 보내지 않는다.
- AC-15: 폭 360px 화면에서는 목록과 상세가 세로로, 데스크톱 폭에서는 나란히 놓이고, 어느 쪽에서도 가로 스크롤 없이 달력과 주요 조작이 모두 보인다.
